# TMPS Design Patterns Labs

A terminal dungeon game that evolves throughout four laboratory assignments.

## Repository structure

```text
TMPS-Labs/
├── Lab1/       SOLID foundation and initial game
├── Lab2/       Lab 1 copy extended with the first pattern group
├── Lab3/       Lab 2 copy extended with the second pattern group
├── Lab4/       Lab 3 copy extended with the third pattern group
├── reports/    Explanation and diagrams for every laboratory
└── TMPS-Labs.sln
```

Every lab is an independent application. Future labs should copy the preceding
lab and evolve that copy instead of referencing its source code. This preserves
the exact implementation submitted for every assignment.

## Run Lab 1

```bash
dotnet run --project Lab1
```
